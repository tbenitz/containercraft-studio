Add Door / Window

Snap opening to 4 in corrugation module

Choose exact dimensions. Windows receive glass + sill framing; doors receive jambs, header and a visible door leaf. Interior partition doors are supported too.

Add Interior Partition

The partition is placed at the selected container center. Use exact X/Z coordinates in the inspector afterward.

Quick Room Builder

Show wall studs / framing

This creates a full-width room at one end of the selected container with a framed partition and a working doorway. Move or edit the new wall afterward if desired.

Stair Builder

Automatically cut roof/floor opening above stair

The stair is generated from actual floor-to-floor rise. Straight flights run along the container length by default so they do not spill through an 8 ft side wall.

Add Pitched Roof

Gable and A-frame roofs create two sloped roof planes and a ridge beam. Shed roofs create one runoff plane. Exact structural sizing still requires load engineering.
